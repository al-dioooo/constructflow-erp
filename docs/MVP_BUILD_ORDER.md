# MVP Build Order

1. Deploy Odoo Community with Docker.
2. Configure company profile and base settings.
3. Create website pages: Home, About, Services, Portfolio, Clients, Contact.
4. Import/create contacts for clients, suppliers, and workers.
5. Configure Project app for construction projects.
6. Configure Purchase app or use the custom Material Purchases model for project material records.
7. Install the Contractor Wage Recap custom module.
8. Test wage recap flow: project -> worker -> wage period -> work days -> total wage -> paid/unpaid.
9. Test material expense flow: project -> supplier -> material purchase -> paid/unpaid.
10. Build weekly project finance recap report.
